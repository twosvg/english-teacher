# Surflect

一个「选中就讲」的英语阅读助手。刷英文内容时遇到不懂的词或句子，不用切出去查——悬浮球点一下就出解析，原 App 一直在。

---

## 它能做什么

| 功能 | 你会得到 |
| --- | --- |
| **生词** | 词性与音标、常见释义、**它在这句话里的意思**、常见搭配、一个例句、易混词 |
| **句式** | 主干（谁做什么）、每段修饰成分挂在哪个词上、断句位置、直译与顺译、句型标志词、难在哪 |
| **翻译** | 中文→英文、英文→中文，各给三个版本（最推荐 / 很随意 / 正式一点）并说明为什么 |
| **批改** | 错误清单、错在哪、更自然的说法、中式英语的成因、一句话要点；中英混写也能改 |
| **追问** | 在结果上继续问，模型带着前面的上下文回答 |
| **笔记本** | 一键把解析存到本机，随时回看、复制、删除 |

默认答案很短，够扫一眼就懂；想深入就追问。

---

## 三种用法

**1. 悬浮球（主推，任何 App 都能用）**

主界面点「悬浮窗」→ 授权「显示在其他应用上层」→ 屏幕上多一个半透明小圆球。

在任意 App 里长按选中文字 → 复制 → 点小球 → 面板贴着屏幕底部滑出，自动读剪贴板。**选好栏目才开始解析**，不会白烧 token。面板里可以切「生词 / 句式 / 翻译 / 批改」，可以追问，可以保存，关掉就回到原来那个 App。

**2. 系统选词菜单**

在支持系统文本菜单的 App（浏览器、备忘录等）里选中文字 → 菜单里点「Surflect」→ 半屏卡片。

**3. 主界面**

手动输入也行：输入框 + 四个按钮 + 结果区，下面是「悬浮窗」「笔记本」，右上角「设置」。

## 界面

- 日间 / 夜间两套配色，跟随系统自动切换
- 解析正文用楷体，字号偏大，长时间看眼睛不累
- 结果里的标题、加粗、列表会自动排版；复制出去是去掉符号的干净文字
- 悬浮球 38dp、半透明，可以拖动换位置，长按可以关掉

## 安装

要求：Android 8.0 及以上。

1. 拿到 `app-debug.apk`
2. 用文件管理器点开
3. 首次会提示「不允许安装未知来源的应用」→ 点设置 → 允许该来源 → 返回继续
4. 装好桌面出现 Surflect 图标

## 首次配置

打开 App → 右上角「设置」：

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| API Key | 空 | 去 https://platform.deepseek.com 申请，形如 `sk-...` |
| 接口地址 baseUrl | `https://api.deepseek.com` | 填 OpenAI 兼容接口。只填域名也行，路径会自动补 |
| 模型名 | `deepseek-chat` | 换服务商时改成对方的模型名 |

填完保存即可。也可以换成任意 OpenAI 兼容服务，只要支持 `stream: true`。

## 隐私

- **选中的文字会原样发送到你配置的那个 API**，否则没法解析。发什么取决于你选中什么。
- **API Key 只存在这台手机上**，写在应用私有目录，只有本 App 能读；系统备份也已关闭。
- 没有统计、没有埋点、没有广告 SDK，也没有自建服务器；除了你配的那个接口，不连接任何地址。
- 安装包是空的密钥，Key 要你自己在手机上填，不会进代码仓库。
- 卸载 App 会同时清掉 Key 和笔记。

## 自己构建

**GitHub Actions（推荐）**

推送到 `main` 会自动构建，打开仓库的 Actions → Build APK → 进这次运行 → 底部 Artifacts 下载 `app-debug.zip`，解压得到 `app-debug.apk`。也可以手动 Run workflow；打 `v*` tag 会自动附到 Release。

**本地**

需要 JDK 17、Android SDK 34、Gradle 8.7：

```bash
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

用 Android Studio 打开项目根目录即可；没有 Gradle Wrapper 时先跑一次 `gradle wrapper --gradle-version 8.7`。

技术栈：纯 Kotlin + 平台 API，不依赖 androidx、Compose 或任何第三方库，JSON 用系统自带的 `org.json`。

## 常见问题

**菜单里找不到 Surflect？**

系统选词菜单只有部分 App 会用。浏览器、备忘录一般可以；有的社交 App 自己画了选择菜单，就不会出现这一项——这时用悬浮球，它盖在所有 App 上面，不需要对方配合。

**提示 401 / 402 / 404**

401 是 Key 不对，402 是余额不足，404 是 baseUrl 填错。到设置里核对一下。

**一直转圈或超时**

网络到服务商不稳，换个网络或在设置里换一个能连通的地址。

**追问框被键盘挡住**

悬浮窗加输入法在个别系统上不会自动上移；可以先把内容打到输入框再发，或者横屏使用。
